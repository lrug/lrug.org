# LRUG.ORG

This repo contains the website of the London Ruby User Group.  It is deployed to
[http://lrug.org][lrug].

The website is a [ruby][] application written using the
[middleman][] framework.  Most of the content is written in
[markdown][] and rendered by [kramdown][].

## Requirements

1. [Ruby][] - the current version is declared in the `ruby` declaration in
   [the `Gemfile` file in the repo](Gemfile).
2. [Bundler][] - the most current version available is likely to be best,
   but you can check the exact version in the `BUNDLED_WITH` statement at the
   bottom of [the `Gemfile.lock` file in the repo](Gemfile.lock)
3. Other dependencies are installed by bundler based on the contents of the
   [`Gemfile`](Gemfile.lock) and [`Gemfile.lock`](Gemfile.lock) files in the
   repo.

## Building

It's a standard middleman app so:

1. Clone the repo locally
2. Install dependencies with `bundle install`
3. Run the application locally with `bundle exec middleman`

## Deploying

Commits to `main` are automatically deployed to [the live site][lrug].

We use [GitHub Actions][actions] to build and deploy the site. Our workflows
live in [`.github/workflows`](.github/workflows), with [`build.yml`][build-yml]
linting and building the site and [`deploy.yml`][deploy-yml] deploying it.

On branches the [build workflow][build-yml] runs linters ([`rubocop`][rubocop]
and [`yamllint`][yamllint]) and then builds the site via
`bundle exec middleman build`.  All of these steps need to pass for the build
to succeed.

On the `main` branch the [deploy workflow][deploy-yml] does all this and also
deploys the website as follows:

1. zips up the `public` folder generated by the build process
2. uploads this zip as a build artefact called `lrug.org.tar.bz2` on the
   [`travis-release`][travis-release] release of this GitHub repo (replacing
   any existing artefact with the same name)
3. triggers a deploy by pinging [our deploy script](deploy-lrug.cgi) at: `http://webhook.lrug.org/deploy-lrug.cgi`
4. the deploy script on our host:
   1. downloads the `lrug.org.tar.bz2` build artefact from the [`travis-release`][travis-release] release on GitHub
   2. unpacks it into the right location on the server using a dated folder
   3. symlinks the most recent to `current` which is the folder served by the webserver

The [`travis-release`][travis-release] release is so named, because this process used to be orchestrated via travisCI, and we just haven't renamed it since porting to Github Actions.
